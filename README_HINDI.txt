GHAR NIRMAN UPDATED ANDROID PROJECT

1. ZIP ko Windows me Extract All karein.
2. Android Studio install/open karein.
3. Open par click karke extracted GharNirmanAndroid_Updated folder select karein.
4. Gradle Sync complete hone dein (pehli baar internet chahiye).
5. Build > Build Bundle(s) / APK(s) > Build APK(s).
6. APK: app/build/outputs/apk/debug/app-debug.apk

Backup:
- App me Backup dabayein. Android Save As dialog khulega. JSON ko Downloads me save karein.
- Restore dabayein aur saved JSON select karein.
- Export CSV dabayein. Android Save As dialog se CSV save karein.

IMPORTANT:
- Purani app ko uninstall/clear data na karein jab tak purana data backup na ho.
- Is project ka applicationId com.gharnirman.app hai. Agar purani APK ka package/signature alag hai to update install karne se pehle data ka backup zaroor karein.
- HTML ke Tailwind, Font Awesome aur Google Fonts CDN references ke karan kuch styling/icons ke liye internet lag sakta hai. Core entry/data functions local HTML me bundled hain.
- Ye Android Studio source project hai, compiled APK nahi.
